# Diário de Enxaqueca

Aplicação web para registro e acompanhamento de crises de enxaqueca.

## Funcionalidades
- Cadastro de crises com sintomas, gatilhos, medicamentos, intensidade, horários e observações
- Visualização dos registros
- Dados salvos em Supabase (banco de dados online)

## Tecnologias
- React + Vite
- TypeScript
- TailwindCSS
- Supabase

## Como rodar localmente

1. Instale as dependências:
   ```
   npm install
   ```
2. Configure o arquivo `src/supabaseClient.ts` com sua URL e chave do Supabase.
3. Rode o projeto:
   ```
   npm run dev
   ```
